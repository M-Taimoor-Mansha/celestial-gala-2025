# ✨ Celestial Gala

A modern, responsive event invitation landing page inspired by an elegant evening under the stars. This project was created as a fun side project to experiment with UI design, animations, and front end development.

## 🌟 Features

- Responsive layout
- Elegant celestial inspired design
- Smooth animations and transitions
- Modern typography and styling
- Clean, lightweight codebase

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/celestial-gala.git
```

Open `index.html` in your browser, or use a local development server.
