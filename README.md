# ✨ Celestial Gala

> **An elegant, celestial themed event invitation landing page built with HTML, CSS, and JavaScript.**

**Celestial Gala** is a front end web project inspired by the beauty of a magical evening beneath the stars. It showcases a modern invitation experience with smooth animations, responsive layouts, and a clean visual design. Although fictional, the project demonstrates how a traditional event invitation can be transformed into an engaging digital experience.

This project was built purely for fun, experimentation, and continuous learning. It serves as a playground for exploring modern front end techniques while focusing on creating an elegant user interface.

---

## 📖 Overview

Traditional invitations are usually static, but modern web technologies make it possible to create interactive experiences that feel much more engaging.

This project recreates the idea of an event invitation as a polished landing page featuring celestial inspired visuals, elegant typography, smooth transitions, and responsive design principles.

The goal was not to build a production application, but to enjoy the creative process while practicing front end development.

The overall design aims to create an elegant and immersive experience.

The inspiration comes from:
